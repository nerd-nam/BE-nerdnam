# 09. 최신 SPEC와 백엔드 현황 (2026-10-26)

## 확인 범위

- SPEC 로컬 `main`의 `bbb835d`, 기획서 **v1.41** 기준이다. 변경 이력에 v1.41이 두 번 있는데 로그인 흐름과 ADR-0006 B10 문구 변경을 각각 뜻한다.
- `git pull --ff-only`는 GitHub DNS 실패로 실행되지 않았다. 네트워크 권한 확대도 실행 정책에서 거절됐다. **원격에 더 최신 변경이 있는지, 현재 열린 PR·이슈가 몇 개인지는 확인하지 못했다.**
- BE의 `fix/spec-v141-integration`은 로컬 `main`(`7ad6c01`)에서 만들었다. 검색 브랜치의 `7875514`·`2105d77`, 웹 계약 예시 수정 `823b50c`를 가져왔다. 기존 브랜치는 보존했다. 로컬 main 반영·푸시·PR 생성은 하지 않았다.

## 이번 검증

- 통합 직후 `./gradlew test`: 기존 **272개 통과**.
- 검증 3개 추가 후 `./gradlew test`: **275개 통과**, 실패·오류·건너뜀 없음.
  - C-04 v0.3.0의 HTTP JSON에서 `expansions`·`min_years`·`p2_v2`를 읽는다.
  - AI 추출 결과 순서가 바뀌어도 요건 id별로 확장하고, 회원별 검색 호출과 판정 입력에 올바르게 연결한다. 확장어를 요건 원문으로 저장하지 않는다.
  - 같은 소셜 계정으로 다시 로그인한 뒤 동의를 재전송해도 두 종류의 동의 기록은 중복되지 않고, 온보딩 상태를 조회할 수 있다.
- 기존 `MeApiTest`가 기술 → 경력 → 프로젝트 검토 → 라이브러리 응답을 검증한다. 실제 웹에서 S05로 이동하는지는 FE 연결 확인이 필요하다.
- 외부 AI 서버는 `AI_MODE=stub`으로 별도 포트에 띄우려 했으나 바인딩이 차단됐다. HTTP 모의 응답 테스트 성공을 **실제 FastAPI 연결 성공으로 간주하지 않는다**.
